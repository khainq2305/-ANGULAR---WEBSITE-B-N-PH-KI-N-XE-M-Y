# Website Kinh Doanh Phụ Kiện Xe Máy Tích Hợp Tính Phí Vận Chuyển GHN

## Mô tả
Website bán phụ kiện xe máy với các tính năng:
- Giỏ hàng, quản lý sản phẩm
- Tính phí vận chuyển tự động qua GHN
- Thanh toán chuyển khoản

## Công nghệ sử dụng
- Frontend: Angular, SCSS, TypeScript, Bootstrap  
- Backend: Node.js, Express, MYSQL
